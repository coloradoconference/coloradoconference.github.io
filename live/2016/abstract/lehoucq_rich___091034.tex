The purpose of my presentation is to investigate classical hypothesis
testing for the stochastic two-block model with variable size blocks or
communities. This model is idealized but
enables analysis and provides the basis for more sophisticated models.
Our results can be used to determine whether an algorithm purporting to
determine two communities is distinct from a randomly generated partition
of the graph.
