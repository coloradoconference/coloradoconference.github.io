Abstract—A Context Aware System (CAS) is a behavior dynamic system which
attributes and functions can rapidly change; causing vital security
challenges that need to be addresses in requirements definition and
modeling phase of CAS development. This paper proposes an adjustment to
Class Diagram, used to model static structure of a system, in order to
model security requirements of a CAS.
