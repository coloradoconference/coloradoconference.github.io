Sparse grids can be used to discretize second order elliptic differential equations on a d-dimensional cube. Using Galerkin discretization, we obtain a linear equation system with unknowns. The corresponding discretization error is in the -norm. A major difficulty in using this sparse grid discretization is complexity of the related stiffness matrix. To reduce the complexity of the sparse grid discretization matrix, we apply pre-wavelets. This simplifies the implementation of the multigrid Q-cylce.
